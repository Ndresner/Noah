# Customer-pay work mix: method (rebuilt and verified Oct 28, 2026)

Each customer-pay labor line in Qlik Cloud (Closed Repair Orders, `c3efc739`) is classified by the wording of its op code description (`RO_Detail.opcodedescription`) using the keyword lists in `build/work-mix-rules.py`. Lines whose description is a placeholder (list G, exact whole-value matches only, e.g. "GENERAL REPAIR", "CUSTOMER STATES") stay unclassified. Maintenance = description matches a pattern in list M and is not a placeholder ({F}={M}-{G}). Repair = matches list R and neither M nor G ({F}={R}-{M}-{G}), so maintenance wins a tie. Unclassified = total minus maintenance minus repair. Rulings: brake work and coolant replace/change are maintenance; repair includes the Oct 15 additions (reseal, gasket, calibration, engine light, drive belt, belt and hose). The measure is CP labor sale (`Sum(RO_Detail.laborsale)`, pay type C), Jan-Sep by close date, 2025 and 2026, same-store 33 stores (INEOS excluded), GMC Prescott body shop labor types excluded, by Division. The raw pull is in `inputs/qlik/work_mix_by_store.json`; `build/wm.json` holds `[store, T25, M25, R25, T26, M26, R26]` and `build/wm.csv` the readable version. Oct 28 reconciliation: group totals tie to the verified CP labor sale ($80,067,347.36 for 2025, $84,966,723.52 for 2026); 2026 group 54.3% maintenance / 30.5% repair / 15.2% unclassified, 2025 unclassified 19.0%; all 33 store 2026 shares match the slide to one decimal (LR Reno and Hyundai Prescott genuinely share 56.8 / 23.9 / 19.3).
